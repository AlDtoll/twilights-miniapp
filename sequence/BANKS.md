## Параметры запуска по сложности

| Сложность | `--time` | Тип испытания |
|---|---|---|
| Лёгкое | 20 | простые герои, новички |
| Среднее | 15 | стандарт |
| Сложное | 10 | опытный герой под давлением |
| Очень сложное | 8 | критическая сцена |

Пороги для 3 вопросов:
```
--thresholds "3:блестяще|2:хорошо|1:слабо|0:провал"
```

Пороги для 4 вопросов:
```
--thresholds "4:блестяще|3:хорошо|2:норм|0:провал"
```

Пороги для 5 вопросов:
```
--thresholds "5:безупречно|4:хорошо|3:норм|2:слабо|0:провал"
```
